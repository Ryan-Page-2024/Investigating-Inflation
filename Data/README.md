# Summary of Data

## File Name: T10YIE
This dataset contains daily observations for the 10-Year Breakeven Inflation Rate (T10YIE) sourced from Federal Reserve Economic Data (FRED).

<br>

## File Name: DCOILBRENTEU
This dataset contains daily observations for Europe Brent Crude Oil Spot Prices (DCOILBRENTEU) sourced from Federal Reserve Economic Data (FRED).

<br>

## File Name: Upper_Breach
This dataset records dates where inflation expectations experienced upper band volatility threshold breaches between 2018 and 2026.

<br>

## File Name: Lower_Breach
This dataset records dates where inflation expectations experienced lower band volatility threshold breaches between 2018 and 2025.

<br>

## File Name: actuals
This dataset contains actual daily observations for the 10-Year Breakeven Inflation Rate (T10YIE) following May, 15th 2026 through January 1st, 2027.
